## 常用命令

```bash
git status              # 看当前有哪些改动
git add .               # 把改动放进暂存区
git commit -m "说明"     # 存成一次提交
git push                # 推送到 GitHub
git pull                # 把远端更新拉回本地
git log --oneline       # 查看提交历史
```
